Drop your screenshots into this folder using these exact filenames:

HERO (3 phones in the top section):
  hero-center.png   — main center phone (e.g. Today view)
  hero-left.png     — left side phone (e.g. Analytics)
  hero-right.png    — right side phone (e.g. Applications list)

SCREENSHOTS CAROUSEL:
  ss-today.png        — Today view
  ss-applications.png — Applications list
  ss-analytics.png    — Analytics / Sankey chart
  ss-add.png          — Add Application screen
  ss-widgets.png      — Widget showcase

APP ICON:
  icon.png            — Your app icon (any size, PNG). Shows in the nav bar and browser tab.

All images should be standard portrait iPhone screenshots (e.g. 1179×2556 px for iPhone 15 Pro).
The phone frame is drawn by CSS so just export plain screenshots — no need to add a device frame yourself.

If a file is missing, a styled placeholder is shown automatically.
